
# Mariyam Chemrah — Developer Portfolio

A modern, interactive portfolio built with Next.js, React, and TypeScript.

This project showcases my work as a Full-Stack Software Engineer, with a focus on scalable applications, thoughtful user experiences, and production-quality development.

## 🌱 About the Project

My portfolio is designed around two distinct experiences:

- **For Recruiters & Engineering Teams:** Explore my professional experience, technical skills, projects, and engineering approach.
- **For Clients & Businesses:** Discover my services, previous work, and how I can help turn ideas into digital products.

Visitors begin with an interactive landing experience and choose the journey that best matches their needs.

The visual concept is inspired by nature, reflecting my personal background and my journey into software engineering.

## ✨ Key Features

- Interactive audience-selection landing page
- Dedicated experience for recruiters
- Dedicated experience for clients

## 🚀 Getting Started

### Prerequisites

- Node.js (compatible with the project's Next.js version)
- npm

### Installation

Clone the repository:

    git clone https://github.com/Mariyame/Mariyam-Chemrah.git

Navigate to the project directory:

    cd mariyam-Chemrah

Install dependencies:

    npm install

Start the development server:

    npm run dev

Open http://localhost:3000/en in your browser.
